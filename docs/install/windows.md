# Installing on Windows

[Back to the README](../../README.md)

## What you need

1. Windows.
2. The **Azahar** emulator ([azahar-emu.org](https://azahar-emu.org/)) or Citra.
3. Your own decrypted copy of Monster Hunter 4 Ultimate (European or American): a `.3ds`, `.cia`, `.zcci` or `.zcia` file. The game update is optional.
4. Optional: your own decrypted copy of Monster Hunter XX (Japanese), for its Layered Gear looks.

## Steps

1. **Download the program.** Download `HeavenfallBeta-windows.zip` from the [latest release](https://github.com/popzol/4u-heavenfall-mod-beta/releases/latest) and extract it anywhere (for example, on your Desktop).
2. **Open it.** Double-click `HeavenfallBeta.exe`. The program is not digitally signed, so Windows may show "Windows protected your PC": if you downloaded it from the official repository, click **More info**, then **Run anyway**. It picks English or Spanish from your system language; you can change it at the bottom of the left panel.
3. **Select your game file.** The **Install** page looks for your game in your emulator's game folders, Downloads, Desktop and Documents. If it can't find it, click **Choose…**. If you have Monster Hunter XX's file, choose it in the row below; it is optional.
4. **Check the destination.** The program finds your Azahar or Citra. If it can't, click **Choose folder…** and select your emulator's folder (in Azahar, **File > Open Azahar Folder > User Folder** opens it).
5. **Choose your options.** The **Options** page has three tabs, one per module, each with its own switch: **Single screen** (the HUD size, the lock-on with L, Kick on Select, the aspect ratio), **Layered gear** (unlocking by rank, the Rare Materials Exchange) and **Other / QoL** (holding A, fast text, the camera's speed, the item boxes, the cheats). A module turned off leaves the game as the original in everything it holds. Hover over any option to see what it does.
6. **Click Install.** If the emulator was running the game, restart emulation. If the button is disabled, the message below it says what's missing.
7. **Play on a single screen.** In Azahar, choose the **Single Screen** layout (View > Screen Layout).

> **Tip:** keep a backup of your save before installing a new mod, just in case.

## Updating, changing options or removing the mod

- **To update:** close the program and open `HeavenfallBeta-update.exe`, in the same folder. It downloads the latest version, replaces the program and rebuilds the mod you installed with the same options. Then restart emulation. If your folder doesn't have that file, download the latest release again.
- **To change your options:** change them on the Options page and click **Update** on the Install page (or **Apply now** on the Options page).
- **To uninstall:** click **Uninstall** on the Install page. The program only removes the files it installed. Materials from Monster Hunter XX and Foreign Scrap then show as unknown items in your save: do not sell or discard them; they come back when you install the mod again.
