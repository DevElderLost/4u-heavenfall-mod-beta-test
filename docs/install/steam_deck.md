# Installing on a Steam Deck

[Back to the README](../../README.md)

> These steps haven't been tried on a real Steam Deck yet. If something doesn't match, please let me know on the [Discord server](https://discord.gg/qQwPRc8CDF).

## What you need

1. **Azahar**, installed in **Desktop Mode** (for example from the Discover store).
2. Your own decrypted copy of Monster Hunter 4 Ultimate (European or American) on the Deck, and optionally Monster Hunter XX (Japanese).

## Steps

Switch to **Desktop Mode**, then use either:

- **The web installer** (nothing to install): open https://popzol.github.io/4u-heavenfall-mod-beta/ in the browser and follow [the web installer's steps](android.md#the-web-installer). To find where the mod goes, in Azahar open **File > Open Azahar Folder > User Folder** and enter `load/mods`. If the browser can't see the SD card, copy the game to Downloads or give the browser access with Flatseal.
- **The program**, from its Linux script: follow [installing on Linux](linux.md). It finds Azahar installed from Flatpak by itself.

Then choose the **Single Screen** layout in Azahar.

## Updating or removing the mod

As on [Android](android.md#updating-or-removing-the-mod) with the web installer, or as on [Linux](linux.md#updating-or-removing-the-mod) with the program.

Problems? See [questions and problems](../faq.md).
